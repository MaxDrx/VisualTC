VisualTC

Visualizador de imagens médicas DICOM: tomografia, ressonância, raio-X e ultrassom. Gratuito e funciona sem internet.

Baixar o VisualTC Escolha abaixo o seu sistema.

O VisualTC é um programa para computador. Abra esta página no computador (Windows, Mac ou Linux) onde você vai ver os exames.

Seu computador

Windows

Windows 10 ou 11 (64 bits)

Baixar para Windows
  1. Clique duas vezes no arquivo baixado.
  2. Clique em Avançar e depois em Concluir. Não precisa de senha de administrador.
  3. O VisualTC abre sozinho. Depois, use o ícone na área de trabalho.
Seu computador

Mac

macOS 12 ou mais novo · chip Apple (M1, M2, M3, M4…) ou Intel

Baixar para Mac
  1. Clique duas vezes no arquivo baixado.
  2. Na janela que abrir, arraste o VisualTC para a pasta Aplicativos.
  3. Abra o VisualTC pelo Launchpad ou pela pasta Aplicativos.
Seu computador

Linux

Ubuntu 22.04 ou mais novo, Debian 12, Linux Mint 21 e outras (64 bits)

Ubuntu, Debian, Mint (.deb)
  1. Clique duas vezes no arquivo baixado.
  2. A Central de Programas abre: clique em Instalar.
  3. Procure VisualTC no menu de aplicativos.

Não apareceu Instalar? No Terminal, na pasta Downloads: sudo apt install ./visualtc_amd64.deb

Outras distribuições (AppImage)

AppImage: clique com o botão direito no arquivo › Propriedades › marque Permitir executar como programa; depois, clique duas vezes. Não instala nada.

Para abrir um exame

Arraste para a janela

A pasta do CD ou do pendrive, ou o arquivo compactado recebido (ZIP, RAR, 7z).

Use os botões

Abrir para arquivos e exames compactados, Pasta para o CD ou uma pasta.

Botão direito (Windows)

No CD, no pendrive, numa pasta ou num ZIP: Abrir no VisualTC.

Apareceu um aviso na primeira vez?

Windows: “O Windows protegeu o computador”

Aparece com programas novos, que ainda não são conhecidos pelo Windows.

  1. Clique em Mais informações.
  2. Clique em Executar assim mesmo.
Mac: “não é possível verificar o desenvolvedor” ou “o VisualTC não foi aberto”
  1. Feche o aviso e abra Ajustes do Sistema › Privacidade e Segurança.
  2. Desça até a mensagem sobre o VisualTC e clique em Abrir Mesmo Assim.
  3. Confirme com a sua senha. Isso só é necessário uma vez.

O VisualTC funciona sem internet: as imagens e os dados dos pacientes não saem do computador.
